# PCB-Design-Development-project
555 Timer Based AC Interface and Control PCB

Designed and developed a compact AC interface and control PCB using KiCad, starting from circuit schematic to final PCB layout and 3D visualization. The design incorporates a 555 timer for timing/control, PC817 optocoupler for electrical isolation, BC546 transistors for switching, and an HLK-10M12 AC-DC power module. Performed component selection, footprint assignment, component placement, PCB routing, labeling, and 3D design verification. The PCB was organized to separate the AC power section from the low-voltage control circuitry, with terminal connectors provided for external connections.

Tools & Technologies: KiCad, PCB Design, Schematic Capture, PCB Layout, 555 Timer, PC817 Optocoupler, Transistor Switching, AC-DC Power Supply, SMD/Through-Hole Components
